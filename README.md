# TOEIC Part 5 Trainer

TOEIC Part 5 문법 문제를 20초 안에 푸는 정적 웹앱 MVP입니다.

## 실행

`index.html`을 브라우저로 열고 `시작하기`를 누르면 문제풀이 화면으로 이동합니다.

## 구성

- `index.html`: 시작 메인 화면
- `practice.html`: 문제풀이 화면
- `styles.css`: 반응형 UI 스타일
- `questions.js`: AI 생성 샘플 문제 데이터 80문항
- `app.js`: 타이머, 채점, 다음 문제, localStorage 기록
- `assets/toeic-practice.png`: 학습용 로컬 이미지

## 데이터 원칙

이 MVP의 문제는 실제 기출 또는 웹 문제를 복제하지 않은 샘플 문제입니다. 공개 서비스로 확장할 때는 허용된 출처 조사, 문법 패턴 추출, AI 신규 문제 생성, 사람 검수 흐름을 사용합니다.
